PHASEBREAK is a single-player Unity 6000.6.1f1 vertical slice. This document records implemented capability and verification limits; GitHub Issues hold actionable work.

## Playable world

- `Assets/Phasebreak/Scenes/StarterZone_V2.unity` is first in build settings. Its four fixed MapMagic terrain tiles cover a 2 km square with a southwest spawn, Northgate, Westmere, Eastwatch, Ancient Ruins, Rift Crypt entrance, six quest NPCs, and 26 encounter zones. `Assets/dashlash.unity` remains the older fallback scene.
- V2 activates nearby zombie encounter zones and respawns them on timers. Ordinary zombies, Brutes, and Skirmishers use the existing enemy, XP, and corpse-loot systems. `docs/reference/STARTER_ZONE_V2.md` describes world ownership, required assets, and rebuilding.

## Implemented systems and ownership

- `Assets/Phasebreak/Scripts` owns third-person movement, jump/air control, camera, targeting, interaction, five combat abilities, Energy, health/death, XP/levels 1–10, inventory/equipment, set effects, specialization, talents, quests, enemy encounters, and Rift Crypt checkpoint recovery. UI and debug tools should use these owners rather than duplicate gameplay state.
- The UI includes player/target frames, action bar, Inventory, Character, Talents, Journal, quest tracker, minimap, schematic world map, a local chat hub, and an Escape game menu with searchable Settings. A reusable dark forged-metal uGUI style foundation supplies rounded charcoal surfaces, subtle metal edges, muted gold accents, and button states. Inventory is a compact right-side bag with smaller slots; the redundant inspection column is removed while item hover/comparison remains. Player and target frames and in-world nameplates use the darker style, and minimap/tracker widths align. Broader equipment layout, panel, and HUD restyling remain open issues. Settings persists keybinding overrides, camera controls, UI scale, screen shake, and video choices through PlayerPrefs. The chat has a metadata-driven developer command registry with generated help, autocomplete, movement/recovery/world/encounter/progression commands, and transient debug overlays. Godmode enables a rebindable cursor-teleport key plus left click; fly and noclip use the configured jump and strafe-left keys to rise and descend, or Ctrl to descend. Gameplay-changing commands run in the Editor or Development Builds. `docs/reference/UI_FUNCTIONALITY_FOLLOWUPS.md` records remaining interface and regression work.
- PlayerPrefs stores progression, inventory/equipment, specialization, talents, quest progress, and selected UI positions. This is local prototype persistence, not an authoritative multiplayer save service.
- Berserker, Bulwark, and Riftblade are freely switchable from the Talent window while alive and outside an executing ability. Each tree retains its own saved allocation and independently uses the level-derived point budget; only the active specialization grants talent effects. Switching clears transient talent buffs, recalculates build and ability modifiers, and reconciles charges without refilling Energy or granting free charges.
- Riftblade has a focused chain-kill slice: collision-respecting Phase Lunge movement, Phase Dash activating Rift Momentum, Energy-only Rift Execution, and one finishing-ability charge restored by Void Circuit or Lunge recovery equipment. Void Circuit also adds 35% Phase Lunge damage. Successful invested kills release the global cooldown and shorten Lunge recovery; ordinary and nonlethal attacks retain their cooldowns. Combat owns a three-second mobility-kill chain, presented as a temporary forged-metal toast with actual Energy/charge restoration, bounded trail/sparks, impact pitch and camera feedback. The first V2 encounter pocket is a deliberately spaced 12-zombie practice lane. Editor/Development commands `/riftbuild apply` and `/riftpack` equip the existing level-10 build and reset/travel to the lane; the loadout saves to the character, preserves owned gear and other specializations' talents, and is idempotent.
- Editor authoring tools live under `Assets/Phasebreak/Editor`; MapMagic 2.1.19 is under `Assets/MapMagic`. Third-party attribution and license files remain with their assets.
